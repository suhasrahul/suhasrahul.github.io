HOARDR: a free-stuff hunting agent with an audit trail

Good free items get posted every day and disappear within hours, buried among junk and scams. HOARDR watches a live free-listings feed, judges every post, drops the junk and alerts you only when something is worth the trip. Every keeper comes with a receipt showing its score, the questions the agent asked, what the photos showed and a price estimate. Built in one day for the brief "a shopping agent with an audit trail."

  • The model answers questions; code makes decisions. One LLM call per listing returns typed answers about authenticity, scams, condition, hazards and fit. Plain code then applies vetoes and a weighted score to mark each listing Keeper, Maybe or Pass.
  • Promising listings get a second, photo-based check: a quality gate for blur, exposure and resolution, then a vision model that tests whether the photos match the text. Unclear photos can never confirm a keeper.
  • Each scan runs as a durable workflow with live event streaming. Claims wait for your one-tap approval and are clearly labeled as simulated.
  • Logs every judgment to SingleStore as the audit trail, keeps a memory of your taste in a Cognee knowledge graph, and checks claim safety with Firedrill drills. Every integration falls back to a local equivalent.

Explainable AI Mobile Photo Editor

An offline iOS and Android photo editor whose AI diagnoses each photo, explains what it found in plain language, and animates real, editable sliders to its suggested values. Its design rule is parameters, never pixels: every AI component outputs labels or slider values, so results stay reversible and explainable and the app stays under 25 MB.

  • Diagnoses images from statistics alone: Rec. 709 luminance histograms, clipping, color-cast channel ratios, saturation and Laplacian sharpness.
  • Renders all pixel processing in GLSL fragment shaders, with live preview and full-resolution export from one parameter set.
  • Generates up to 25,000 training labels from MIT-Adobe FiveK by porting the shader to a differentiable PyTorch function and fitting 7 parameters to 5 experts' edits.
  • Trains a MobileNetV3 model that predicts a bounded residual over a rule-based baseline, with out-of-distribution confidence, shipped as INT8 TensorFlow Lite.
  • Evaluated with per-parameter MAE, SSIM and PSNR against baselines, plus a blind preference study.

HueInvert: Hue-Preserving Dark Mode for Any macOS Window

A menu-bar app that turns a single window dark with ctrl + I while keeping every color's hue, so red errors stay red and blue links stay blue. Built for light sensitivity, low vision and eye strain; a macOS take on GNOME's True Color Invert.

  • Captures the window with ScreenCaptureKit, inverts only HSL lightness in a Metal shader, rgb + (1 − max − min), and draws it into a click-through overlay synced to the display refresh.
  • Privacy by design: no network code and nothing written to disk; frames live in GPU memory for milliseconds.
  • Ships as a universal DMG with a SwiftUI onboarding guide that detects and repairs stale Screen Recording permissions.
